# پوشهٔ دروس

منبع حقیقتِ **محتوای** درس همین پوشه است، نه رابط کاربری (ADR-0008).

## افزودن محتوا

یک پوشه به نام درس بسازید و فایل‌ها را داخلش بگذارید:

```
Courses/
  Traffic Safety/
    course.yml          ← اختیاری
    کتاب SUMO.docx
    پادکست ایمنی.pdf
```

بعد یک بار همگام‌سازی کنید:

```bash
make courses-sync                     # همه‌ٔ دروس
make courses-check                    # گزارش بدون نوشتن
make courses-sync a="--course 'Traffic Safety'"
```

فایلی که در `course.yml` نامش نیامده باشد **حذف نمی‌شود، حدس زده می‌شود**:
نوع ماده از نام و پسوند فایل درمی‌آید. `course.yml` فقط حدس سامانه را
دقیق‌تر می‌کند؛ لازم نیست پیش از افزودن هر فایل ویرایشش کنید.

فایلی که از پوشه ناپدید شود `ARCHIVED` می‌شود، نه حذف — پس جابه‌جایی یا
ذخیرهٔ دوبارهٔ Word پیوند هفته‌ها و تاریخچهٔ دسترسی را از بین نمی‌برد.

## چه چیزی در Git است

**فقط `course.yml` و همین راهنما.** خودِ کتاب و جزوه و پادکست کامیت
نمی‌شوند (`.gitignore`): مخزن جای ۱۰ مگابایت PDF نیست و محتوا عمر و
چرخهٔ بازبینی خودش را دارد. یعنی مخزن می‌گوید هر درس **چه چیزی** دارد،
و دیسک آن را **دارد**.

در استقرار تازه: پوشه را کپی کنید و `make courses-sync` بزنید.

## سطح دسترسی

در `course.yml`، هر ماده یک `access_tier` دارد (ADR-0009):

| سطح | چه کسی می‌بیند |
|------|-----------------|
| `PUBLIC` | همه، حتی بدون ورود |
| `SUBSCRIBER` | دانشجوی درس رایگان؛ بقیه با اشتراک |
| `ENROLLED` | فقط دانشجوی ثبت‌نام‌شدهٔ درس |

اگر ننویسید، `default_access_tier` درس اعمال می‌شود.
