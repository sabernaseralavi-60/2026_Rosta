# راهنمای رُستا

رُستا جایی است که درس، پروژهٔ واقعی، پژوهش و کسب‌وکار دانشجویی کنار هم
پیش می‌روند. این راهنما برای کسانی است که با سامانه کار می‌کنند، نه برای
برنامه‌نویسان.

| اگر… | این راهنما را بخوانید |
|------|----------------------|
| دانشجو هستید | [راهنمای دانشجو](student.md) |
| دانشجوی دانشگاه نیستید و برای یادگیری آمده‌اید | [راهنمای کاربر عمومی](public-learner.md) |
| درس یا پروژه را اداره می‌کنید | [راهنمای استاد و منتور](instructor.md) |
| مدیر یا پشتیبان سامانه‌اید | [راهنمای مدیر](admin.md) |
| سؤال مشخصی دارید | [پرسش‌های پرتکرار](faq.md) |

## سه چیز که از روز اول به کار می‌آید

1. **ورود فقط با موبایل است.** رمز عبوری در کار نیست؛ هر بار کد شش‌رقمی
   پیامک می‌شود.
2. **هر جا گیر کردید، Ctrl + K** (در مک ⌘ + K) را بزنید و بنویسید دنبال
   چه هستید — درس، پروژه، ایده، فرد یا یک کار مثل «ثبت ایده».
3. **امتیاز فقط از کار تأییدشده می‌آید.** تحویلی که هنوز بررسی نشده، امتیاز
   ندارد؛ این عمدی است تا عددها واقعی بمانند.

## پشتیبانی

اگر چیزی کار نمی‌کند، از پیام خطا عکس بگیرید — هر پیام خطا یک **کد پیگیری**
دارد — و برای پشتیبانی درس یا گروه پشتیبانی سامانه بفرستید. با آن کد،
مشکل شما در چند دقیقه پیدا می‌شود.
